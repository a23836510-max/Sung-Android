# Sung Android

Android port of the open-source Sung music player.

## Foundation

- Kotlin
- Jetpack Compose
- Material 3
- Android Media3 / ExoPlayer
- Android API 26+
- GitHub Actions APK build

## Roadmap

- Local music library
- Background playback
- MediaSession
- Queue and mini-player
- Playlists and favorites
- Lyrics
- Search
- Online providers
- Themes and polished mobile UI
